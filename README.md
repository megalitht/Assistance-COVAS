# COVAS : ASSISTANT DE BORD POUR ELITE DANGEROUS
Ce projet est en lien direct avec le jeu Elite Dangerous d'où le nom du projet.
L'origine de ce projet tiens à un manque d'immersion. je cherchais a avoir un veritable interaction avec le jeu. puis un beau jour, sur les réseau sociaux, je suis tombé une des vidéo de Joffre_Tiboy dont il a présenté sont projet de JEAN-BOT.
Le Covas est une assistance de bord écrit principalement en python. il est capable de comprendre des commandes vocals. interagir avec le jeu, alerter des infos, donner des indications tout en gardant une bonne fluidité. le COVAS n'est pas une intelligence artificiel, toute ses réponses sont des répliques préenregistrés.
